# 奇門遁甲解讀

`kinqimen-mcp` 只回事實：邊粒星落邊宮、邊道門配邊個天干、值符值使喺邊。**判斷全部係你嘅工作。**
呢份文件講點樣由事實行到判斷，同埋邊啲嘢唔准做。

> **草稿聲明**：以下取用神同格局部分，係按《煙波釣叟歌》、《奇門遁甲統宗》一路嘅通用學理，
> 加上原 repo `data/system_prompts.json` 四個 persona 嘅取向整合而成，**未經流派校訂**。
> 各家取用神有出入（尤其求財、官非、疾病三類），用之前請按自己師承核對。

---

## 零、鐵律

1. **每一句判語都要指得出係邊個 tool result 邊一欄。** 講唔出出處嘅嘢唔好講。
2. **唔准補盤。** 盤上冇嘅嘢（例如某粒星唔喺盤上）就係冇，唔准推一個出嚟。
3. **時間要明文。** 起「而家」嘅盤，先 `resolve_time`，再將佢個 `datetime` 傳落去。
   引擎唔會自己讀時鐘，你亦唔准假設。
4. **拆補定置閏由用戶揀。** 兩派結論會唔同，冇邊派係「正確」。
   用戶冇講就問，或者兩派都排出嚟並列，唔好靜靜雞幫佢揀。
5. **唔講死。** 奇門係參考，唔係判決。涉及健康、法律、財務嘅問題，
   講完盤象之後要明確叫用戶搵專業人士。
6. **法術奇門（閉六戊）唔主動出。** 用戶明確問先 call `get_closed_sixwu`，
   而且要問清楚佢要演義版定寶鑑版——兩個傳承方向相反，冇預設。

## 一、起盤流程

```
用戶問事
  ↓
時間邊度嚟？  ── 用戶有講 → 直接用
              └ 冇講「而家」 → resolve_time（傳問事人所在地時區）
  ↓
排局法邊個？  ── 用戶有講 → 用佢揀嗰個
              └ 冇講 → 問，或者兩派並列
  ↓
get_qimen_chart（時家為主）
  ↓
需要更精細 → get_qimen_chart_minute（刻家）
需要日課   → get_golden_mirror_chart（金函玉鏡）
  ↓
check_patterns（格局）
  ↓
解讀
```

用戶如果追問「點解今日係呢個局」，或者你想比較兩派差幾遠而唔想排成個盤，
用 `get_ju`：佢淨回三個局名，加埋置閏法嘅完整推導（距節氣日數、三元、四個候選局）。

**時家 vs 刻家 vs 金函**：
- **時家** — 主力。一個時辰一盤，占事、擇時、方位都用佢。冇特別理由就用時家。
- **刻家** — 十分鐘一盤。用喺要分得好細嘅時候（同一個時辰入面幾單嘢、或者問「而家」呢一刻）。
- **金函玉鏡** — 一日一盤，日課性質。問「今日整體點」、揀日子嗰陣用。

## 二、取用神

奇門解盤第一步係**搵用神**——即係代表所問之事嘅嗰個符號。搵錯用神，成盤都白讀。

### 恆定用神（每盤都要睇）

| 符號 | 代表 | 由邊度攞 |
|---|---|---|
| **值符** | 求測人／主事者／整體大勢 | `zhifuZhishi.zhifuStar` |
| **值使** | 事情嘅發展過程同結果 | `zhifuZhishi.zhishiDoor` |
| **日干** | 求測人本身 | `pillars.day[0]`，再喺 `earthPlate` 搵佢落邊宮 |
| **時干** | 所問嗰件事／對方 | `pillars.hour[0]`，同上 |

**日干宮同時干宮嘅關係，係全盤最重要嘅一組。** 睇兩宮五行生剋、睇兩宮嘅門星神。

### 按事類取用神

| 問咩 | 用神 | 備註 |
|---|---|---|
| 求財 | 生門 | 兼睇日干宮同生門宮嘅生剋 |
| 事業／官職 | 開門、值符 | 開門主官貴 |
| 婚戀 | 男看庚、女看乙；六合 | 六合主婚姻媒妁 |
| 疾病 | 天芮星、死門 | 天芮為病星。**只講盤象，一定要叫佢睇醫生** |
| 官非訴訟 | 值符（我）、庚（對方）、杜門 | 杜門主隱蔽、和解 |
| 出行 | 驛馬（`horses.yiMa`）、開門 | 兼睇馬星落宮 |
| 尋人尋物 | 天心星、六合 | 六合主藏匿之所 |
| 考試文書 | 天輔星、景門 | 景門主文書 |
| 合作 | 六合、日干與時干兩宮 | |

用戶問嘅嘢唔喺表上，就講清楚你用邊個做用神、點解——唔好靜靜雞揀。

## 三、讀盤次序

搵到用神之後，照呢個次序讀，唔好跳：

1. **值符值使落宮** — 大勢。值符宮旺唔旺、值使門吉唔吉。
2. **用神落宮** — 該宮嘅天盤干、地盤干、門、星、神，五樣一齊睇。
3. **天地盤干嘅組合** — 天盤干臨地盤干，就係「十干克應」。
   奇（乙丙丁）遇儀（戊己庚辛壬癸）為順，儀壓奇為逆。庚為最凶之儀（值符飛宮、車馬、阻隔）。
4. **門、星、神三者同宮位五行嘅生剋** — 門生宮為吉、宮剋門為凶，如此類推。
   五行查 `lookup_reference`（門星有五行，宮有五行）。
5. **旺相休囚死** — 用 `lookup_reference` category `jieqi` 查當前節氣邊個五行旺。
   同一道生門，旺相同休囚死判若兩事。
6. **空亡同馬星** — `kong` 入面嘅地支落宮就係空亡宮：主事情落空、拖延、不實。
   馬星主動、主變、主遠行。
7. **格局** — `check_patterns` 回嘅三個格局；成形就係加重砝碼，唔成形唔使提。

## 四、格局

`check_patterns` 回三個上游有實作嘅格局：

| 格局 | 條件 | 一般理解 |
|---|---|---|
| **青龍返首** | 天盤戊臨地盤丙 | 大吉。謀事有成、絕處逢生 |
| **飛鳥跌穴** | 天盤丙臨地盤戊 | 大吉。主意外之喜、事半功倍 |
| **玉女守門** | 地盤丁與值使門同宮 | 主和合、私密之事順、宜見貴人 |

**呢三個唔係奇門格局嘅全部。** 其餘吉凶格（乙奇得使、三奇得使、白虎猖狂、螣蛇夭矯、朱雀投江、青龍逃走⋯⋯）
`kinqimen-mcp` 冇做判定，要你自己由 `get_qimen_chart` 嘅 `skyPlate` / `earthPlate` / `doors` / `stars` / `gods`
逐宮組合去讀。讀嗰陣要講明你係點砌出嚟嘅。

## 五、輸出格式

一份完整解盤應該有：

1. **盤面摘要** — 時間、干支、排局、節氣、值符值使。可以用 `render_chart_text` 出個九宮圖。
2. **用神交代** — 你揀咗咩做用神、點解。
3. **逐層推演** — 照上面第三節嘅次序，每一步指明睇緊邊一欄。
4. **結論** — 吉凶傾向、時機、方位。用「盤象顯示⋯」而唔係「你一定會⋯」。
5. **建議** — 可行動嘅嘢。方位就講清楚係邊個宮對應邊個方向（`lookup_reference` category `palace` 有方位）。

長度睇問題：一個簡單問題唔使寫五頁。

## 六、常見陷阱

- **中宮無門。** 中宮唔配八門，`doors` 入面冇 `中` 係正常，唔好當佢係漏數據。
- **值符入中宮時，天盤得八宮。** `skyPlate` 冇 `中` key 係中宮寄坤之後嘅正常結果。
- **23:00 已經算第二日子時。** 所以 22:59 同 23:01 嘅日柱唔同——呢個係晚子時慣例，唔係 bug。
- **刻家嘅 `kong` 係時空同刻空**，唔係時家嗰個日空時空。
- **金函玉鏡嘅 `craneGod` 多數係 null**，而且有值嗰陣回嘅係重複字元 list 唔係方位。
  嗰個係上游資料表本身唔完整，唔好當方位讀，唔好硬砌解釋。
- **引擎唔做真太陽時。** 用戶如果係遠離時區中央經線嘅地方（例如新疆），
  應該提佢一句：傳入嘅係鐘錶時間，傳統排盤可能會校真太陽時。校唔校由佢決定。
